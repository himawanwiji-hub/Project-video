# Isometric Microchip & Circuit Board — Canvas API

Kode JavaScript Canvas murni untuk video microstock 15 detik (3 scene × 5 detik, 16:9, loop seamless).
Setiap file berisi `function draw(ctx, time, width, height)`; `time` dalam detik.

| File | Konsep |
|---|---|
| `nomor-1-neon-core-assembly.js` | Lapisan CPU turun dan menumpuk, jalur sirkuit menyala, core berdenyut |
| `nomor-2-data-highway-city.js` | Motherboard sebagai kota: gedung chip tumbuh, paket data melaju di jalan, jendela LED berkedip |
| `nomor-4-quantum-grid-pulse.js` | Grid 5×5 chip: gelombang radial, gelombang diagonal, lalu pola komputasi paralel |
| `nomor-5-circuit-bloom.js` | Jalur tembaga tumbuh dari chip, komponen muncul, arus mengalir, lalu semuanya ditarik kembali |
