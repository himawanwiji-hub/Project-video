# Port Distribution Center — Canvas API

Kode JavaScript Canvas murni untuk video microstock 15 detik (3 scene × 5 detik, 16:9, loop seamless),
gaya isometrik clean vector dengan tipografi poster. Setiap file berisi `function draw(ctx, time, width, height)`; `time` dalam detik.

| File | Konsep |
|---|---|
| `nomor-1-harbor-flow.js` | Kapal kontainer merapat, dua crane STS membongkar ke truk, truk berangkat, kapal pergi |
| `nomor-2-container-yard-grid.js` | Kontainer jatuh dan menumpuk, crane RTG memindahkan kontainer, lalu sapuan scan inventori |
